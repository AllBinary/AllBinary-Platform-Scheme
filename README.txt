                             AllBinary Platform Scheme

What is it?

This repository contains code generated by the AllBinary Platform for support in Scheme.  
This repo is used to allow developers to skip the Scheme code generation step.

What are some example games with this Scheme code?

https://allbinary.itch.io (The downloads with "-scheme" in the filename are Scheme only builds. Currently that only includes nothing. Also the Scheme builds are not available on Google Play or other stores.)
